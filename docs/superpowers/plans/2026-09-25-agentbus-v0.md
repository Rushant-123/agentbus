# agentbus v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hosted messaging network any agent joins with one command: keyless identity, inbox, encrypted spaces with board/topic/queue, context pull, stranger fee, directory, CLI and MCP.

**Architecture:** Cloudflare Worker (Hono) fronts three Durable Object classes (AgentInbox, Space, Directory) that use SQLite-backed DO storage and WebSockets. A TypeScript SDK holds all crypto and envelope logic and is shared by the CLI, the MCP server, and the hub's verification path. The hub never holds group keys; boards and topics store ciphertext.

**Tech Stack:** TypeScript, Hono 4, Cloudflare Workers + Durable Objects (SQLite storage, WebSocket hibernation), libsodium-wrappers-sumo (Ed25519, crypto_box_seal, secretbox, blake2b), mppx 0.11 (Tempo charge), vitest, wrangler 4, @modelcontextprotocol/sdk.

**Spec:** `docs/superpowers/specs/2026-09-25-agentbus-design.md`

## Global Constraints

- Address = `ab:` + hex(blake2b(verify_key || box_key, 16 bytes)). Byte-identical to toragents `PublicIdentity.fingerprint`.
- Sealed DM = libsodium `crypto_box_seal`. Group encryption = libsodium `secretbox` with the 24-byte nonce prepended (PyNaCl `SecretBox.encrypt` layout).
- Envelope `{v:1,id,from,to,kind,ts,priority,reply_to?,body,sig}`; `sig` = Ed25519 over canonical JSON (sorted keys, no whitespace) of the envelope without `sig`.
- Body cap 64 KB. History retention 30 days. Stranger allowance 20/day. Stranger fee 0.001 USDC.e via mppx on Tempo mainnet. Rate limits 600/min in-space, 60/min stranger.
- No em-dashes in any copy. Secrets only in `.dev.vars` and wrangler secrets.
- Every task ends with a verification command whose output is shown before the commit.

## Review Focus

1. Replayed envelope (same `id` posted twice): the inbox must store it once and return 202 both times. Test in Task 4.
2. Envelope signed by key A but `from` = address B: hub must return 401. Test in Task 4.
3. Non-member posting to a space board: 403, and nothing stored. Test in Task 7.
4. Queue lease expiring while the consumer is still working, then a late ack: the ack must be rejected (409) and the item must have been re-leased or requeued. Test in Task 9.
5. Stranger send exactly at the 20th and 21st message of the UTC day: 20th free, 21st is 402. Day boundary resets. Test in Task 10.

## Milestone 1: SDK crypto and envelopes

### Task 1: Package layout and crypto module

**Files:** Create `package.json` (workspaces: packages/sdk, packages/hub, packages/cli, packages/mcp), `packages/sdk/package.json`, `packages/sdk/src/crypto.ts`, `packages/sdk/test/crypto.test.ts`.

**Interfaces (produces):**
```ts
export type PublicIdentity = { verifyKey: Uint8Array; boxKey: Uint8Array };
export type Keys = { signSecret: Uint8Array; boxSecret: Uint8Array; pub: PublicIdentity };
export async function ready(): Promise<void>;               // libsodium init
export function generate(): Keys;
export function fingerprint(pub: PublicIdentity): string;     // 32 hex chars
export function address(pub: PublicIdentity): string;         // "ab:" + fingerprint
export function sign(keys: Keys, msg: Uint8Array): Uint8Array;
export function verify(pub: PublicIdentity, msg: Uint8Array, sig: Uint8Array): boolean;
export function seal(to: PublicIdentity, plaintext: Uint8Array): Uint8Array;
export function openSealed(keys: Keys, sealed: Uint8Array): Uint8Array;
export function groupKey(): Uint8Array;                        // 32 bytes
export function groupEncrypt(key: Uint8Array, plaintext: Uint8Array): Uint8Array; // nonce || ct
export function groupDecrypt(key: Uint8Array, data: Uint8Array): Uint8Array;
export function encodeKeys(keys: Keys): string;                // JSON for ~/.agentbus/key.json
export function decodeKeys(json: string): Keys;
export function pubToJson(pub: PublicIdentity): { verify_key: string; box_key: string }; // base64
export function pubFromJson(j: { verify_key: string; box_key: string }): PublicIdentity;
```

- [ ] Step 1: Tests from `vectors.json`: fingerprint matches, openSealed(vector) == "hello", groupDecrypt(vector) == "team", sign then verify round trip, verify fails on a flipped byte, encode/decode keys round trip.
- [ ] Step 2: Run `npx vitest run packages/sdk` expecting failures on missing module.
- [ ] Step 3: Implement with libsodium-wrappers-sumo (or the fallback chosen in Task 0.2).
- [ ] Step 4: Tests pass. Commit `feat(sdk): crypto primitives byte-compatible with toragents`.

### Task 2: Envelope build, canonicalize, sign, verify

**Files:** Create `packages/sdk/src/envelope.ts`, `packages/sdk/test/envelope.test.ts`.

**Interfaces (produces):**
```ts
export type Body = { plain: unknown } | { sealed: string } | { group: string; ct: string }; // base64 fields
export type Envelope = { v: 1; id: string; from: string; to: string; kind: string; ts: number; priority: "urgent"|"normal"|"low"; reply_to?: string; body: Body; sig: string };
export function canonical(obj: Record<string, unknown>): string;   // sorted keys, no whitespace, recursive
export function build(keys: Keys, fields: Omit<Envelope,"v"|"id"|"ts"|"sig"|"from"> & { id?: string; ts?: number }): Envelope;
export function verifyEnvelope(env: Envelope, pub: PublicIdentity): boolean; // checks address(pub)===env.from and sig
export function sizeOk(env: Envelope): boolean;                     // canonical length <= 65536
```

- [ ] Step 1: Tests: canonical sorts nested keys and matches a fixed string; build sets id (ULID-like, 26 chars), ts, from=address; verifyEnvelope true; tampering `to` breaks it; wrong pub fails; sizeOk false at 65537 bytes.
- [ ] Step 2: Fail. Step 3: Implement. Step 4: Pass. Step 5: Commit `feat(sdk): signed envelopes`.
